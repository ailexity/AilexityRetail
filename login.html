Settings

The public address is what invoice links in WhatsApp messages point at. Leave it blank to use the server's APP_URL; if neither is set the link falls back to whatever address the app is open on, which customers cannot reach from outside the shop.

The currency formats every amount shown to superadmins and retailers. The country code is added to 10-digit mobile numbers when invoices are sent on WhatsApp. Retailers see the support contact under Help & support.

The expiry warning drives the "expiring soon" alert and the dashboard note. Session length applies to new sign-ins.

Other superadmin sessions are signed out when the password changes. The new password replaces the one in the server configuration.
